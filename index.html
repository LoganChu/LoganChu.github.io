Memory Arena — what agent memory actually costs

Seven agent-memory backends — BM25, dense vectors, entity and temporal knowledge graphs, agent-authored notes — benchmarked against three control-flow styles (single-shot, a model-driven loop, an explicit LangGraph retrieve/assess cycle) on one fixed task suite, scored on accuracy and on token spend split by read, write, and decide. The harness earns its keep by catching real bugs before they become false conclusions: on a 3B local model, entity_graph scored 0.00 against BM25’s 0.56, not because graphs are worse but because k-hop retrieval matched query terms against fact subjects only, missing every fact stored as an object. Fixed, and locked in with a regression test.

02 Aug 26

Measuring what actually trains in a MoT

Instruments a small Mixture-of-Transformers to answer what the architecture diagram won’t: does the modality with less data get trained less? With image tokens at 14% of the stream, the image expert still moves 1.04× as far from init as the text expert — under Adam. Swap in SGD and it drops to 0.69×. But equal movement is not equal quality: held-out image loss still degrades 0.936 → 1.134, and two predictions stated before the runs came back not confirmed. Part II carries the same instrumentation to NVIDIA Cosmos 3, whose two-tower reasoner-and-diffusion stack is a MoT in all but name.
